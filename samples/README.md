# Samples

Small files for the manual checklist ([docs/TESTING.md](../docs/TESTING.md)). All were generated by a script in the previous, Python version of PixelKit (`backend/scripts/make_http_samples.py`), so there are no third-party rights.

| File | What it checks |
|---|---|
| `transparent.png`, `transparent.webp`, `transparent.avif` | 640×480 art with transparency: alpha kept, or filled with a warning |
| `logo.png` | 512×512 with transparency: ICO, favicon, PNG → SVG |
| `photo.jpg` | JPEG with EXIF orientation 6: must come out upright |
| `fake-extension.png` | `photo.jpg` with a `.png` name: must be detected as JPEG |
| `detailed.jpg` | 1000×750 detailed photo-like image: compression |
| `with-metadata.jpg` | JPEG with a camera make and a comment: metadata removed by default |
| `plain.bmp` | 320×240 BMP |
| `animated.gif` | Two-frame GIF: "only the first frame" warning |
| `screenshot-portrait.png`, `screenshot-landscape.png` | Store screenshots in both orientations |
| `corrupt.png` | First half of a PNG: "damaged file" error |
| `random.bin` | 4 KB of random bytes: "format not supported" error |
| `too-many-pixels.png` | 11000×10000 (110 MP) in 29 KB: must be refused before decoding |
